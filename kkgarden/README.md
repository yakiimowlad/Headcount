# Клеверник

Мини-игра КуулКлевер: растим клевер на подоконнике, пока едет заказ.

Один HTML-файл. Ноль зависимостей. Ноль медиафайлов — звук синтезируется
в браузере. Открывается двойным кликом.

**Версия 0.4.0** · [План релизов](ROADMAP.md)

```
open kkgarden/index.html
```

Прогресс — в localStorage, ключ `kk-garden`.

## Что это

Фоновая игра внутри приложения доставки. Растение растёт само, в том числе
пока приложение закрыто.

Цикл суточный и собран из трёх слоёв:

- **40 секунд** — десять тапов по солнцу дают ровно одну стадию.
- **3 минуты** — полить, зайти в магазин, в альбом, отдать корешок соседу.
- **Сутки** — вернуться утром за распустившимся цветком: 30 КеГЛей на карту
  и росинки на инвентарь.

Фаза бутона длится восемь часов, поэтому раскрытие всегда переезжает через
ночь: сколько по бутону ни тапай, за одну сессию он не раскроется. Обратного
отсчёта нигде нет — только слово «раскроется к утру».

Новые семена дают не за деньги, а за задания и за корешки от соседей.
Задания в прототипе подтверждаются кнопкой «Выполнено» — бэкенда нет нигде.

## Корешок соседу

Отдаёшь отросток случайному игроку и узнаёшь только имя: «Корешок ушёл
Татьяне». Сосед отвечает тем же: «Корешок от Ольги — василёк». Ответный
корешок открывает сорт, которого у вас нет, — это единственный путь
к василькам, лаванде, маку и пиону.

Всё на клиенте: адресат случайный, ответ приходит по таймеру, в том числе
пока игра закрыта. В тестовой сборке ответ идёт 45 секунд, чтобы петлю можно
было пройти за одну сессию. Один корешок в пути за раз.

## Дизайн

Стилистика — крупная казуальная игра: скруглённые панели, толстые сливочные
канты, сочные вертикальные градиенты.

Кнопка собрана из трёх слоёв — жёсткая подошва цветом тёмной грани, корпус с
градиентом и кантом, внутренний блик сверху. Нажатие уводит корпус ровно на
высоту подошвы, и подошва исчезает: получается настоящая клавиша. Цвет и
размер задаются классом, геометрия у всех общая.

```html
<button class="gbtn g-gold">Собрать · +60</button>
<button class="gbtn g-cream sm">Поставить</button>
```

Семейства: `g-green` `g-gold` `g-blue` `g-pink` `g-violet` `g-cream`.
Размеры: по умолчанию, `sm`, `xs`. Модификаторы: `wide`, `full`, `calm`
(«делать нечего» — спокойная кремовая вместо мёртвой серой).

## Звук

Ни одного файла: `AudioContext`, два примитива — осциллятор с огибающей и
белый шум через полосовой фильтр. Из них собраны пятнадцать событий и фоновый
слой с редкой птицей днём и сверчком ночью.

Ноты берутся из мажорной пентатоники, поэтому наложения всегда консонанс.
Тапы по солнцу поднимаются по ступеням — дневной лимит слышно раньше, чем
видно.

Контекст создаётся при первом касании (политика автоплея). При выключенном
звуке узлы не создаются вообще. Переключатель — в шапке, выбор сохраняется.

## Кнопка «Тест»

Фиолетовая клавиша на подоконнике. Открывает панель: время суток, прогресс
(росинки, тапы, стадии, бутон, влага, семена, магазин), прогон всех звуков,
корешки и сброс.

Для суточного цикла там же две нужные кнопки: **«Промотать час»** двигает
реальный рост на час вперёд, **«Ответный корешок сейчас»** не ждёт таймера.

В продакшене её быть не должно — удаляется вместе с `#devbtn` и `#devsheet`.

## Проверка

```
npm install
node kkgarden/test/screens.mjs   # снимки экранов + ошибки в консоли
node kkgarden/test/audio.mjs     # граф WebAudio: узлы создаются, при выключении — нет
node kkgarden/test/audit.mjs     # регрессии аудита 0.3.1
node kkgarden/test/gift.mjs      # корешки, КеГЛи и суточный темп
```

Все скрипты запускаются из корня репозитория — `playwright` лежит там.
Снимки складываются в каталог, указанный переменной `OUT` (по умолчанию — `/tmp`).
